- 分辨率：480P
- 帧率：模型固定 24fps
- 摄影机：固定
- 音频：不生成音频轨

- 图片2：只锁定成片最后一帧的完整爆炸构图、部件顺序、分离方向和最终间距。
- 图片3：只锁定 SPD01 正面外观、前后透明玻璃、黑色框架、把手、桌板、座椅与正面比例。
- 图片4：只锁定 SPD01 三分之四外观、灰绿色侧板、灰色吸音板、顶部、底座、纵深比例和材质。

## 产品锁定卡

- 唯一主体：一台 SPD01 灰绿色单人静音舱，产品数量始终为 1。
- 固定外观：高而窄的圆角矩形舱体、黑色顶盖和底座、灰绿色右侧实体板与立柱包件、灰色左侧吸音板。
- 固定透明件：黑框透明前玻璃门一扇，原把手始终附着在同一门框；黑框透明后玻璃一块，无把手。
- 固定附件：白色桌板始终刚性连接左侧吸音板；绿色坐垫黑色支架座椅始终保持完整、直立并接触地面。
- 拆分模块：顶板 1、左侧吸音板 1、右侧实体板 1、前玻璃门 1、后玻璃 1、立柱包件 4、地毯/底座 1。
- 严禁变化：不得增加灰色内部墙，不得把后玻璃变为吸音板，不得复制门、侧板、立柱、桌板或座椅。

## API 主提示词

参考图片1至图片4，生成一支 6 秒、16:9、480P 的高端工业产品爆炸动画。图片1只规定第一帧，图片2只规定最后一帧；图片3和图片4是 SPD01 外观、结构、颜色、玻璃、框架、把手、桌板、座椅和材质的唯一依据。四张图片属于同一台 SPD01，产品数量始终为 1。不要把素材排成四宫格，不要在画面中显示参考图边框。

固定平视、正面三分之四视角、约 50mm、中等偏深景深，摄影机全程完全固定。产品始终位于画面中央，垂直线保持笔直，深炭黑无缝影棚和地面不变化。

镜头开始：完整 SPD01 保持图片1的组装状态并稳定停留约 0.8 秒。前玻璃门和后玻璃都是真实透明玻璃，能够透射深色背景，只出现克制的冷白竖向反射；左侧灰色吸音板、右侧灰绿色实体板、黑色框架、白色桌板和绿色座椅清晰可辨。底座与座椅均有连续柔和的接触阴影。

随后进行一次连续、缓慢、具有惯性的广告式轴向拆解：所有部件先同时出现极窄缝隙，再沿各自固定直线轴平稳分离。顶板垂直向上；左侧灰色吸音板连同白色桌板作为一个刚性模块缓慢向左；右侧灰绿色实体板缓慢向右；黑框透明前玻璃门连同原把手作为一个刚性模块向画面右前方平移，不执行开门旋转；黑框透明后玻璃作为单一透明模块沿纵深向后平移；四根立柱包件分别从四角沿径向小幅向外；座椅保持直立和刚性，贴地向左前方缓慢移动一小段；地毯与黑色底座始终位于画面中心并保持接地，不抬升、不旋转。

拆解过程从小间距自然扩大到图片2的最终爆炸位置。所有部件速度先缓慢加速，再平滑减速，同时保持原始朝向、比例、材质和前后遮挡关系；部件之间不穿插、不交换位置、不突然跳到终点。前玻璃门和后玻璃在整个运动中持续透明，黑框边缘稳定，背景透射和竖向反射连续，绝不变成灰色毛毡、实体黑墙、磨砂板或绿色板。

最后约 1.5 秒到达图片2的完整爆炸构图并稳定停留。顶板、左右侧板、前门、后玻璃、四根立柱、底座和座椅清晰分层，仍能直观看出它们可以沿原路径重新组合成一台 SPD01。主光来自左上方，约 5200K；轮廓光窄而克制；接触阴影、玻璃反射和地面明暗随零件位移连续变化。高端工业产品广告风格，真实三维材质，运动安静、精确、克制。

保持无字幕，避免生成任何文字或字幕，不生成 Logo，不生成水印。禁止四宫格、分屏、拼贴、工程编号和箭头；禁止产品数量变化、比例变化、颜色漂移、灰色内部墙、玻璃不透明、玻璃闪烁、把手脱离门框、附件消失或复制、立柱增减、桌板脱离吸音板、座椅变形、底座漂浮、部件旋转翻滚、穿插、融化、重影、双重边缘、瞬间跳位、镜头移动、镜头抖动、广角畸变和背景切换。

## 独立负面约束

禁止四宫格或参考图拼贴；禁止把后玻璃生成灰色吸音板、黑色实体墙或磨砂板；禁止舱内残留第二块左侧吸音板；禁止复制前门、后玻璃、左右侧板、桌板、座椅或立柱；禁止零件跳变、穿模、漂浮、随机旋转和相互换位；禁止字幕、文字、编号、箭头、Logo 与水印。
